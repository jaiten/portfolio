# Jaiten Kang — Portfolio

The source for [jaitenkang.com](https://jaitenkang.com), my portfolio for applied AI, product engineering, browser extensions, and client work.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js and React
- Framer Motion
- Plain CSS with a custom editorial design system
